# 📷 MẮT MỘT MÍ MEDIA – HỆ THỐNG QUẢN LÝ THIẾT BỊ & MÁY ẢNH CƯỚI

Web App quản lý toàn bộ thiết bị, máy ảnh, lens, đèn, máy tính và phụ kiện quay chụp cưới cho **Mắt Một Mí Media**. Tối ưu trải nghiệm sử dụng trên cả **điện thoại di động (Mobile)** và **máy tính (Desktop)**.

---

## 🌟 TÍNH NĂNG NỔI BẬT ĐÁP ỨNG TOÀN DIỆN YÊU CẦU

### 1. Quản lý nhân sự
- **Hồ sơ & Tài khoản**: Tạo tài khoản cho từng nhân sự (Photographer, Videographer, Stylist, Kỹ thuật...).
- **Phân quyền 3 cấp**:
  - 👑 **Admin**: Toàn quyền cấu hình, quản lý nhân sự, khóa/mở tài khoản, xuất báo cáo.
  - 🛡️ **Quản lý (Manager)**: Quản lý kho thiết bị, tạo đợt kiểm kê, duyệt bàn giao.
  - 📷 **Nhân sự (Staff)**: Mượn trả thiết bị, quét QR kiểm tra, bàn giao chéo trực tiếp.
- **Không chia team cố định**: Nhân sự phối hợp linh hoạt đi các show cưới khác nhau, có thể trực tiếp chuyển giao thiết bị cho nhau.
- **Khóa tài khoản bảo toàn dữ liệu**: Khi nhân sự nghỉ việc, tài khoản bị vô hiệu hóa đăng nhập nhưng **toàn bộ lịch sử mượn trả, hình ảnh bàn giao trước đây được giữ nguyên 100%**.

### 2. Quản lý tài sản studio
- Quản lý danh mục: Máy ảnh (Body Sony A7IV, FX3, Canon R6 II), Lens (24-70 GM II, 70-200 GM II, 50 f1.2...), Đèn Flash/Led (Godox AD600 Pro, Nanlite Pavotube...), Gimbal (DJI RS 3 Pro), Máy dựng MacBook Pro, thẻ nhớ và phụ kiện.
- **Đầy đủ định danh**: Mỗi món có Mã tài sản riêng (vd: `MMM-CAM-001`), hình ảnh thực tế và mã QR code riêng biệt.
- **Phân biệt 2 vai trò**:
  - **Người phụ trách**: Quản lý chịu trách nhiệm tài sản dài hạn.
  - **Người đang giữ**: Nhân sự đang cầm thiết bị thực tế tại hiện trường / show cưới.

### 3. Quản lý mã QR
- **Quét QR thông minh**: Hỗ trợ camera điện thoại trực tiếp, tải ảnh chụp tem QR, hoặc tra nhanh mã thiết bị.
- **In tem QR dán thiết bị**:
  - Giao diện in tem chuẩn thẩm mỹ Studio với logo "MẮT MỘT MÍ MEDIA", mã vạch QR sắc nét, mã tài sản và tên thiết bị.
  - Hỗ trợ in 1 tem hoặc in hàng loạt toàn bộ thiết bị theo dạng decal dán máy.
- Bảo mật: Người dùng phải đăng nhập và phân quyền hợp lệ mới được thực hiện bàn giao.

### 4. Quy trình mượn – trả hai bên nghiêm ngặt
- **Bàn giao trực tiếp (Peer-to-peer)**: Nhân sự có thể chuyển giao máy ảnh, lens trực tiếp cho nhau tại phim trường hoặc studio.
- **Minh bạch thông tin**: Ghi nhận người giao, người nhận, thời gian và hạn trả dự kiến.
- **Chụp ảnh hiện trạng**: Bắt buộc/khuyến nghị chụp ảnh tình trạng ngoại quan lúc giao và lúc nhận để tránh tranh chấp trầy xước, vỡ kính.
- **Quy tắc 2 bên xác nhận**:
  - Người trả **không được tự xác nhận** đã nhận lại.
  - Thiết bị chỉ chuyển sang trạng thái 🟢 **Sẵn sàng** (hoặc người giữ mới) khi **người nhận lại vào xác nhận**.

### 5. Hệ thống 4 trạng thái màu trực quan
- 🟢 **Xanh**: Sẵn sàng sử dụng (Đang ở kho studio).
- 🟡 **Vàng**: Đang có người giữ (Đi show cưới, đang trong hạn mượn).
- 🟠 **Cam**: Chờ xác nhận giao nhận hoặc trả (Yêu cầu đang chờ người nhận bấm xác nhận).
- 🔴 **Đỏ**: Quá hạn trả, hư hỏng, mất thiết bị hoặc có vấn đề kỹ thuật cần bảo trì.

### 6. Dashboard Admin thông minh
- Xem tổng quan toàn bộ thiết bị và nhân sự.
- Tra cứu tức thì: Thiết bị đang ở đâu, ai giữ, khi nào phải trả.
- **Cảnh báo thiết bị quá hạn**: Nổi bật ngay đầu trang chủ để quản lý kịp thời đôn đốc thu hồi.
- Theo dõi các giao dịch chờ xác nhận, báo cáo hỏng hóc hoặc mất mát.

### 7. Kiểm kê thực tế & Đối soát sai lệch
- **Quét QR kiểm kê**: Cầm điện thoại quét QR từng máy ảnh/lens tại kho hoặc xe đoàn.
- **Tự động đối soát sai lệch**:
  - Sai lệch vị trí (VD: Hệ thống ghi ở kho nhưng thực tế đang ở cốp xe).
  - Sai lệch người giữ (VD: Hệ thống ghi Tuấn giữ nhưng thực tế Đăng đang cầm).
  - Sai lệch tình trạng.
- **Xuất dữ liệu & Báo cáo**: Xuất file CSV (tương thích Excel) và in biên bản kiểm kê trực tiếp.

## 🛠️ CÔNG NGHỆ TRIỂN KHAI

- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS, Lucide Icons, Canvas Confetti.
- **QR Engine**: `qrcode`, `jsqr` (quét camera + xử lý ảnh canvas chuẩn xác trên mọi trình duyệt).
- **Backend & Database**: **Supabase** (PostgreSQL, Row Level Security, Auth, Storage).
- **Hosting**: **Vercel** (Deploy tự động qua GitHub).
- **Trải nghiệm tức thì**: Hệ thống tích hợp sẵn Mock Data & Local Storage cho phép chạy thử và kiểm thử mọi tính năng ngay lập tức kể cả khi chưa gắn khóa Supabase API.

## 🚀 HƯỚNG DẪN CÀI ĐẶT & CHẠY DỰ ÁN

### 1. Chạy trên máy cục bộ (Localhost)
```bash
# 1. Cài đặt các thư viện (đã cài sẵn)
npm install

# 2. Khởi động môi trường phát triển
npm run dev
```
Truy cập trình duyệt: `http://localhost:3000`

---

### 2. Kết nối cơ sở dữ liệu Supabase

1. Truy cập [https://supabase.com](https://supabase.com) và tạo một Project mới (ví dụ: `mat-mot-mi-media`).
2. Vào mục **SQL Editor** trong Supabase Dashboard.
3. Mở file `supabase/schema.sql` trong dự án, dán toàn bộ nội dung vào SQL Editor và bấm **Run**.
4. Vào mục **Project Settings -> API** để lấy:
   - `Project URL`
   - `anon public key`
5. Tạo file `.env.local` tại thư mục gốc dự án:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
```

---

### 3. Triển khai lên Vercel & GitHub

1. Đưa mã nguồn lên GitHub:
```bash
git init
git add .
git commit -m "Khoi tao he thong quan ly thiet bi Mat Mot Mi Media"
git branch -M main
git remote add origin https://github.com/your-username/mat-mot-mi-equipment.git
git push -u origin main
```
2. Đăng nhập [https://vercel.com](https://vercel.com) -> Chọn **Add New Project** -> Chọn repository vừa tạo.
3. Trong phần **Environment Variables**, điền 2 biến môi trường Supabase:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. Bấm **Deploy**. Vercel sẽ tự động build và cấp link web app sử dụng toàn cầu cho anh em studio.
